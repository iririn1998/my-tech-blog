このブログ自体の話です。SPA 構成だった旧ブログを Astro で作り替え、クライアント JS をほぼゼロにしました。

## 移行の手順

記事は Markdown + Content Collections に寄せ、一覧・詳細・タグページはすべてビルド時に静的生成しています。frontmatter に zod スキーマで型が付くので、記事データの扱いがアプリコードと同じ感覚で書けます。

## Islands をどこに残したか

残した島は検索ボックスだけです。それ以外の UI は静的 HTML と CSS で成立しており、フレームワークを乗せる理由がありませんでした。「島を増やさない」という制約は、設計をシンプルに保つ良い枷になっています。

## 結果

Lighthouse のパフォーマンスは安定して100、ビルドは全ページで10秒未満。何より、記事を書くことに集中できる構成になりました。
