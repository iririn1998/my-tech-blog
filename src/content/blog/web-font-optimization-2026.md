日本語 Web フォントは1書体で数 MB になります。それでも CLS を出さずに読み込む定石は、この数年でほぼ固まりました。

## サブセット化と preload

まず使用文字でサブセットを作り、woff2 で配信します。ファーストビューで使う書体だけを `<link rel="preload">` し、残りは `font-display: swap` で遅延させるのが基本形です。

## size-adjust でフォールバックを合わせる

swap 時のリフローを抑える鍵は、フォールバックフォントの寸法調整です。`size-adjust` と `ascent-override` でシステムフォントを本命フォントの寸法に合わせておけば、切り替わりはほぼ気づかれません。

## 計測

最適化の成否は CLS と LCP で判定します。フォントが LCP 要素のレンダリングをブロックしていないか、DevTools の Performance パネルで確認して仕上げます。
