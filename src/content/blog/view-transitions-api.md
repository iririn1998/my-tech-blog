SPA の専売特許だったページ遷移アニメーションが、素の MPA でも書けるようになりました。仕組みは「遷移前後のスクリーンショットをブラウザがクロスフェードする」— それだけです。

## 基本の書き方

MPA では CSS を1行足すだけで有効になります。

```css
@view-transition {
	navigation: auto;
}
```

要素単位で動かしたい場合は `view-transition-name` を前後のページで一致させます。カード → 詳細ヘッダーのような接続が CSS だけで成立します。

## 実務での注意点

遷移名はページ内で一意である必要があるため、一覧ページでは動かしたいカードだけに動的に名前を付けます。また、アニメーション中は操作がブロックされるので、時間は 300ms 以内に抑えるのが無難でした。
