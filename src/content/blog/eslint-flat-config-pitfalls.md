.eslintrc からの移行は「設定形式の変換」ではなく「解決モデルの変更」です。ここを取り違えると、動いているように見えて実は当たっていないルールが生まれます。

## 共有設定の読み込み

`extends` は消え、共有設定は配列に直接スプレッドする形になりました。旧形式の shareable config は `FlatCompat` を経由しないと読めません。移行期間中は compat 経由の設定がどれかをコメントで明示しておくと、後で外し忘れません。

## plugin の名前空間

Flat Config では plugin の名前空間を自分で決められます。裏を返すと、チーム内で名前がぶれると同じルールが別名で二重定義されます。旧来の慣習名をそのまま使うのが安全でした。

## 当たっていることを確認する

移行後は `eslint --print-config` で対象ファイルの最終設定を必ず確認します。「エラーが出ない」は「ルールが当たっている」を意味しません。
